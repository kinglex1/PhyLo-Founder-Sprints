## Overview

Sprint 3 is the pricing phase. The goal is to test pricing with real customers, build a Revenue Model that can scale, map the human and agent roles needed to deliver, and present a Metrics Review to Mentors at the Weekly Strategy Presentation. By the end of Sprint 3, PhyLo has a defensible pricing model anchored against the SA telematics competitors, a unit-economics story, a team plan with a clear top hire, and a 5-slide deck rehearsed to under 3 minutes.

**The framing constraint (from Qhayiya, 6 Jun 2026):** PhyLo is **not** a telematics competitor. It is an audit-grade analysis layer that **reads the customer's existing telematics feed** and produces a month-end document the telematics dashboards cannot. The market reads it as a competitor, so the pricing, the pitch, the deck, and the comparison table all have to make the layer-not-replacement framing unmissable — usually in the first 30 seconds and the first slide.

## Sprint Outcomes

**Pricing model chosen:** Diagnostic-led, customer-choice. 30-day free diagnostic, then Path A (R45/vehicle, default for typical customers) or Path C (R1,500/mo + R1,500/event, default for high-variance like the pilot). See [`Set-2-Revenue-Model/`](./Set-2-Revenue-Model/).

**Unit economics (Path A, default — honest, corrected from a 12x math error in the earlier draft):** LTV R29,160 (3-year lifetime × R32,400/year × 30% margin), CAC R12,000-25,000, LTV:CAC 1.2-2.4x (below the 3x SaaS bar), payback 4.4-9.3 months. **The deck's headline is the customer's 22x ROI** (R720k+/year recovered, R32k paid), not PhyLo's own LTV:CAC.

**Combined-bill defensibility (the constraint that shaped the price):** Cartrack R220/vehicle + PhyLo Path A R45/vehicle = R15,900/month on 60 trucks = **20.5% premium on Cartrack alone** (R2,700 / R13,200 = 20.45%, rounded). Defensible as a "layer." R150/vehicle (earlier draft) would have been 60-75% above Cartrack — indefensible.

**Top hire:** Sales Lead / Founding Account Executive (R25-35k/month base + 5% closed ARR)

**6-month run cost:** R69,400 (R50k human comp + R4.4k agent APIs + R15k tool subs)

**Pilot pricing chosen:** Path C (R1,500/mo + R1,500/event, no cap), expected R9,000-13,500/month pilot revenue at 5-8 events

**Deck:** 5 slides rehearsed to <3 minutes
