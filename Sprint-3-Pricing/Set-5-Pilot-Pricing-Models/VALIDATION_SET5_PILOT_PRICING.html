The pilot partner has R78k/month variance and 5-8 confirmed events per month — that is the highest-variance customer PhyLo will ever have. Path A would underprice PhyLo at this variance (R1,890/month on the pilot-concession R45 rate = 2.4% take-rate). Path B has the right alignment but no cashflow floor. Path C is the chosen default for the pilot specifically: the R1,500 floor covers PhyLo's fixed costs for the diagnostic period, the R1,500/event is half of Path B's R2,000 so the partner pays less per event in exchange for the floor, and the resulting R9-13.5k/month take is ~12-17% of recovered value — defensible as a "fair share." For the typical (lower-variance) customer, Path A is the right pitch. The pilot is the case study that proves Path C works for high-variance customers; Path A is the default for everyone else.

Expected first-month revenue: R9,000-13,500/month (assuming 5-8 confirmed events per the pilot dataset).
