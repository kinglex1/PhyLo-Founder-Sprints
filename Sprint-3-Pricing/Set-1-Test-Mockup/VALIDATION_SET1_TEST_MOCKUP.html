Part 1 — The Three Pricing Concepts

The Initial Mockup (committed in Sprint 2 Set 3) gets a new "Pricing" tab. The framing line is the first thing the customer reads.

Path A — Default for typical customers
Per-vehicle subscription (tiered)
R45 / vehicle / month

Tiered: R35 (100-200 trucks), R25 (>200 trucks). Includes dashboard, monthly audit report, alerts, 1 dispute pack/quarter.

"Less than a fifth of your Cartrack bill. Sits on top, not in place of."
Path B — Default for risk-averse customers
Per-incident only (no floor)
R0 floor + R2,000 / event

No monthly fee. R2,000 per confirmed theft above 85% confidence. Includes detection engine, evidence pack, monthly report.

"Pay nothing monthly. R2,000 per theft event PhyLo proves."
Path C — Default for high-variance customers (pilot only)
Soft floor + per-incident
R1,500 / month + R1,500 / event

Floor covers up to 200 vehicles. Per-event R1,500 (half of Path B). Cheapest defensible position vs. Cartrack+PhyLo combined bill.

"R1,500 floor + R1,500 per proven event. ~20% of recovered value."
All three paths start here

30-day free diagnostic. PhyLo reads your telematics feed, produces a baseline loss report. You see your actual loss number in writing before you pick a path. The diagnostic is the sale.

Part 5 — Will They Pay? (anticipated synthesis)

Working hypothesis (to be confirmed by 5 sessions)

YES — Path A (per-vehicle subscription at R45) wins for the typical customer; Path C (soft-floor + per-incident) wins for high-variance customers like the pilot partner. Customers resist Path B because the cashflow is too lumpy. Customers resist a per-vehicle price above R45 because the combined Cartrack+PhyLo bill then looks 60-75% above Cartrack — indefensible. The 30-day free diagnostic defuses the price objection because the customer has seen their R60k variance in writing before they see the price. Customers say they will pay when they have a documented R60k+ monthly variance to defend — which is the only decision state where this product matters.

Top 3 requested changes (anticipated)

1. "Make the dashboard read-only for drivers" — security / data-access concern raised by every finance director persona
2. "Give me a sample report for finance, in PDF, with the R78k number" — the sell tool is the report, not the dashboard
3. "What does 'confirmed theft' actually mean — define it in the SOW" — contractual hot zone; the 85% confidence threshold needs to be in writing
