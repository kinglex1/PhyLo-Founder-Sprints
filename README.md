## File Format Convention

Each FI deliverable is produced in two formats:
- **`.md`** — Markdown source for pasting into the FI editor
- **`.html`** — Standalone visual version for sharing and presentation

The HTML version mirrors the Markdown content with FI-style formatting applied (dark theme, monospace accents, color-coded sections).

## How to Use This Repository

1. **For FI editor submission:** Open the relevant `.md` file in each Set folder, copy the content, paste into the FI editor
2. **For review or sharing:** Open the corresponding `.html` file in any browser
3. **For the current state:** Read `00_PROJECT_OVERVIEW.md` and `00_SYNTHESIS.md`
4. **For the mockup:** Open `Sprint-2-Validation/Set-3-Initial-Mockup/VALIDATION_SET3_MOCKUP.html` in any browser — it's an interactive prototype
