# START HERE — Instructions for All Agents Welcome! Before starting any task on this project, please follow these steps: ## Step 1: Identify Your Agent ID Find your assigned ID from `00_PROJECT_OVERVIEW.md`: | Agent ID | Chat | Folder | |----------|------|--------| | `AGENT-001` | This chat | `CHAT_A/` | | `AGENT-002` | Chat B | `CHAT_B/` | | `AGENT-003` | Chat C | `CHAT_C/` | **You are:** `AGENT-001` (unless otherwise assigned) ## Step 2: Read the Project Overview Read `00_PROJECT_OVERVIEW.md` to understand the project goals and context. ## Step 3: Check Existing Work Look in the relevant chat folder to see what has already been done. Avoid duplicating work. ## Step 4: Save Your Work Properly When you complete a task: 1. Save your main output to your folder: `CHAT_[X]/[AGENT-ID]_[filename].md` 2. Include your **Agent ID** at the top of every file as a header 3. Add a summary to `00_SYNTHESIS.md` with: - **Agent ID:** (e.g., AGENT-001) - What you did - Key findings/decisions - Any dependencies on other agents' work - Next steps or open questions ## Step 5: Cross-Reference If your work relates to another agent's output, mention their **Agent ID** in your summary and link to their file. --- ## Quick Reference | Agent ID | Role | Save to | Read first | |----------|------|---------|------------| | AGENT-001 | Research | `CHAT_A/` | `CHAT_B/`, `CHAT_C/` | | AGENT-002 | Analysis | `CHAT_B/` | `CHAT_A/` if research exists | | AGENT-003 | Production | `CHAT_C/` | `AGENT-001/`, `AGENT-002/` | --- ## Need Context from Another Chat?
